# Proyecto Hackathon - Inventario de Computadoras
Autor: Medalid Chaparro

Instrucciones rápidas:
1. Editar src/main/java/medalid/chaparro/database/Conexion.java con tu endpoint RDS, usuario y contraseña.
2. Ejecutar src/main/java/medalid/chaparro/resources/sql/script.sql para crear la BD y la tabla.
3. Compilar con `mvn package` e iniciar la app ejecutando la clase ProjectApplication.
4. Para JasperReports: compilar el jrxml a .jasper y ajustar rutas de recursos.

Estructura:
src/main/java/medalid/chaparro/
controller/
database/
model/
service/
view/
resources/sql/
src/main/resources/jasper/
